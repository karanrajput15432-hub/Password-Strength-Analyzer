# Password Strength Analyzer

* Description:
A Python-based tool that analyzes password strength and estimates the time required to crack it using brute-force techniques.

* Features:
- Detects common passwords
- Calculates password strength score (0–100)
- Provides security recommendations
- Estimates crack time based on character set and length

* Technologies Used:
- Python
- Regular Expressions (re)
- File Handling

* How to Run:
1. Make sure Python is installed
2. Run the script:
```bash
python password_strength_analyzer.py
